# ➕ Counter Program

A counter with **Decrease**, **Reset** and **Increase** buttons.

## Run
Open [`index.html`](index.html) in a browser.

## How it works
- `count` starts at `0` and lives in one variable.
- Each button has its own `onclick` that updates `count`.
- After every change, `countlabel.textContent` shows the new value.

## Files
| File | Role |
|---|---|
| [`index.html`](index.html) | Count label + three buttons |
| [`index.js`](index.js) | State and click handlers |
| [`style.css`](style.css) | Styling |
