# 🎰 Random Number Generator

One click rolls three random numbers between 1 and 6.

## Run
Open [`index.html`](index.html) in a browser → **Roll**.

## How it works
- Each click generates three values with `Math.floor(Math.random() * max) + min`.
- Each value is shown in its own label.

## Files
| File | Role |
|---|---|
| [`index.html`](index.html) | Roll button + three result labels |
| [`index.js`](index.js) | Random number logic |
| [`style.css`](style.css) | Styling |
