## 🚀 Run a project

```bash
git clone https://github.com/israqxaman2/Javascript-Achievements.git
```

Open any project's `index.html` in your browser. There's nothing to install.

## 🧠 Concepts practiced

| Area | Topics |
|---|---|
| **DOM** | `getElementById` · `textContent` · `innerHTML` · event handlers |
| **Logic** | `if / else` · `while` and `for` loops · validation |
| **Data** | variables · arrays · `Number()` · `toFixed()` · template literals |
| **Functions** | parameters · return values · ternary operator |
| **Randomness** | `Math.random` · `Math.floor` |
| **Inputs** | text, number, checkbox, radio, `prompt` / `alert` |
