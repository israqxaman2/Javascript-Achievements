# ✅ Subscribe

A small form: tick a subscribe checkbox, pick a payment method, submit.

## Run
Open [`index.html`](index.html) in a browser → choose options → **Submit**.

## How it works
- Checkbox → shows **subscribed** or **NOT subscribed**.
- Radio group (Visa, MasterCard, PayPal) → shows the chosen method.
- No payment selected → asks you to choose one.

## Files
| File | Role |
|---|---|
| [`index.html`](index.html) | Checkbox, radio buttons, submit, result text |
| [`index.js`](index.js) | Reads `.checked` states and shows results |
| [`style.css`](style.css) | Styling |
